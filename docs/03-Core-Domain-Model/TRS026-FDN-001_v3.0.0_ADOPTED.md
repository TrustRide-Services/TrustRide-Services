7. **Every engine migration carries the constitutional engine manifest header** (Annex D.1): platform identity, engine identity, domain, class, type, versioning, migration data, installation order, status, authorship. `[Trace: TBOC-v1.0.0 | Page: 30 | Article: 59 | Paragraph: —]`

```sql
event_outbox (
  signal_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  causation_id      UUID NULL,                  -- the signal that caused this signal

  attempt_count     INTEGER NOT NULL DEFAULT 0, -- retry discipline; on exhaustion the signal goes to dead_letter_review

  receiving_engine  TEXT NOT NULL,
  signal_type       TEXT NOT NULL,
  payload_in        JSONB NOT NULL,
  payload_out       JSONB NULL,
  signal_status     TEXT NOT NULL DEFAULT 'RECEIVED',  -- RECEIVED · ACCEPTED · REJECTED · DEAD_LETTER
  rejection_reason  TEXT NULL,
  idempotency_key   TEXT NOT NULL UNIQUE,
  attempt_count     INTEGER NOT NULL DEFAULT 0,
```

### Deferred Foreign Keys — TRS_FDN_IDENTITY internal forward references

Annex A's table numbering (020–050) is fixed by the adopted constitutional text and is not reordered for DDL convenience. Two columns within the Identity subsystem reference a sibling table declared later in that same numbered order; their foreign key constraints are therefore added here, immediately after the full `TRS_FDN_IDENTITY` group exists, rather than inline in their `CREATE TABLE` statement.

```sql
-- [Trace: TBOC-v2.0.0-ENG1-IDENTITY-DEFERRED-FK]
ALTER TABLE user_authentication ADD CONSTRAINT fk_user_authentication_device_id FOREIGN KEY (device_id) REFERENCES user_device (device_id);
ALTER TABLE user_employment ADD CONSTRAINT fk_user_employment_entity_id FOREIGN KEY (entity_id) REFERENCES entity_profile (entity_id);
```

### N.9 Index Discipline (Phase 9)

Per Annex E Phase 9, every foreign key column carries a supporting B-tree index, every `idempotency_key` and `*_code`/`*_key` UNIQUE column is indexed by its UNIQUE constraint, and every ledger table indexes its status and timestamp columns for operational querying. The general pattern applied uniformly across all 92 tables:

```sql
-- [Trace: TBOC-v2.0.0 | FDN-001 Annex E Phase 9 — Indexes]
-- Pattern (applied per-table above the domain layer, generated at migration time):
--   CREATE INDEX idx_<table>_<fk_column> ON <table> (<fk_column>);
--   CREATE INDEX idx_<table>_status        ON <table> (status)         WHERE status IS NOT NULL;
--   CREATE INDEX idx_<table>_created_at     ON <table> (created_at);
-- Envelope tables additionally carry:
```
